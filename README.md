# 图片压缩 pic · 拖进来，下压好的图

> 大图拖进来，定一个长边和质量，右边实时给出压缩前后的大小、尺寸和省下多少，点一下下载。图片不上传，刷新就清空。

[English](README.en.md) | 中文

## 这是什么

发邮件、传后台，动不动就卡在「图片不能超过 2MB」。这页把压缩放在浏览器里做：canvas 重绘加 toBlob 重新编码，图从打开到下载全程没离开过本机。

长边按比例缩，小图不放大；格式可选 JPG / WebP / PNG，PNG 忽略质量滑块（无损）。PNG 转 JPG 时先铺一层白底，不然透明区域会变黑。带 EXIF 方向信息的手机照片用 createImageBitmap 的 imageOrientation 选项读，竖拍的照片不会被躺倒。

打开就自带一张现画的 2400×1600 示例图（canvas 画的渐变加圆点），不用先找图才知道怎么用。实测示例图：281.5 KB 到 76.4 KB（长边 1600、质量 80），省 73%。

## 功能

- 拖拽或点选，JPG / PNG / WebP 都能进
- 长边与质量两个滑块，结果实时更新
- 前后并排预览，标出像素、体积、省下百分比
- 输出 JPG / WebP / PNG，PNG 自动忽略质量
- EXIF 方向正确处理，竖拍照片不会躺倒
- 打开自带示例大图，不用先找图
- 全程本地计算，图片不上传
